# Backend con .NET

Curso de **Raptor Dev Services Academy**. Las clases como presentación, el quiz y el avance están en [academy.raptorcloud.dev/dotnet-backend/](https://academy.raptorcloud.dev/dotnet-backend/); aquí está todo el material en Markdown, y las lecturas son notas de este mismo repositorio.

Result, pipeline y validación, EF Core, PostgreSQL avanzado, JWT, pruebas, caché y tareas en segundo plano.

**Formato:** 6 módulos de 2 h (12 h). Cada módulo trae clase, quiz y glosario.
**Para quién:** quien construye el backend de un producto en .NET.
