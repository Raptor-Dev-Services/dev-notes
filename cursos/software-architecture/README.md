# Diseño y arquitectura de software

Curso de **Raptor Dev Services Academy**. Las clases como presentación, el quiz y el avance están en [academy.raptorcloud.dev/software-architecture/](https://academy.raptorcloud.dev/software-architecture/); aquí está todo el material en Markdown, y las lecturas son notas de este mismo repositorio.

Planificación, arquitecturas comparadas, diseño de APIs y administración de un equipo de software.

**Formato:** 4 módulos de 2 h (8 h). Cada módulo trae clase, quiz y glosario.
**Para quién:** quien diseña software y necesita elegir arquitectura, contratos de API y proceso de equipo.
