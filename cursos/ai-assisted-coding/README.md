# Vibe coding profesional

Curso de **Raptor Dev Services Academy**. Las clases como presentación, el quiz y el avance están en [academy.raptorcloud.dev/ai-assisted-coding/](https://academy.raptorcloud.dev/ai-assisted-coding/); aquí está todo el material en Markdown, y las lecturas son notas de este mismo repositorio.

Programar con asistentes de IA con criterio: contexto, prompts, flujo de trabajo y LLMOps.

**Formato:** 1 módulo de 2 h (2 h). Cada módulo trae clase, quiz y glosario.
**Para quién:** quien programa con un asistente de IA y quiere resultados que resistan una revisión.
