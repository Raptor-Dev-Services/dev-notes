# Git, Docker, CI/CD y nube

Curso de **Raptor Dev Services Academy**. Las clases como presentación, el quiz y el avance están en [academy.raptorcloud.dev/devops-essentials/](https://academy.raptorcloud.dev/devops-essentials/); aquí está todo el material en Markdown, y las lecturas son notas de este mismo repositorio.

**Formato:** 5 módulos de 2 h (10 h). Cada módulo trae clase, quiz y glosario.
**Para quién:** quien lleva su aplicación del repositorio a producción.
