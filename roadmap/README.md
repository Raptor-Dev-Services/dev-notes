# Roadmaps de Aprendizaje — dev-notes

Rutas de estudio estructuradas usando los documentos de este repositorio como guía.
Cada roadmap indica el orden de lectura, los prerequisitos y qué puedes construir al terminar.

---

## Roadmaps disponibles

| Roadmap | Nivel inicial | Duración estimada | Objetivo |
|---------|--------------|-------------------|---------|
| [C#](roadmap-csharp.md) | Sin experiencia en C# | 3-4 semanas | Dominar el lenguaje |
| [Backend .NET](roadmap-backend-dotnet.md) | C# intermedio | 6-8 semanas | APIs REST production-ready |
| [Arquitectura](roadmap-arquitectura.md) | Backend junior | 4-6 semanas | Diseño de sistemas escalables |
| [SaaS Multi-Tenant](roadmap-saas-multitenant.md) | Backend senior | 8-12 semanas | Producto SaaS completo |
| [DevOps](roadmap-devops.md) | Desarrollador junior | 4-6 semanas | Git + Docker + CI/CD + Cloud |
| [Frontend](roadmap-frontend.md) | Sin exp. en React | 3-4 semanas | SPA con React 19 + Tailwind v4 |
| [Patrones de Diseño](roadmap-patrones.md) | C# intermedio | 4-5 semanas | GoF completo + ASP.NET Core |

---

## Cómo usar los roadmaps

1. **Elegir un roadmap** según tu objetivo y nivel actual
2. **Leer en el orden indicado** — cada fase tiene prerequisitos de la fase anterior
3. **Practicar con el back-template** — los ejemplos de código corresponden al proyecto real
4. **Marcar tu progreso** — usa la lista de checkboxes en cada roadmap

---

## Ruta recomendada para un desarrollador nuevo en el stack

Si estás empezando desde cero con este stack (.NET 10 + Clean Architecture + PostgreSQL + React):

```
1. C# (3-4 semanas)
       ↓
2. Backend .NET (6-8 semanas)
       ↓
3. Patrones de Diseño (paralelo con Backend, 4-5 semanas)
       ↓
4. Arquitectura (4-6 semanas)
       ↓
5. DevOps (4-6 semanas, puede ser paralelo con Arquitectura)
       ↓
6. Frontend (3-4 semanas, puede ser paralelo)
       ↓
7. SaaS Multi-Tenant (8-12 semanas — el objetivo final)
```
